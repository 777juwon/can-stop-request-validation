# 졸업논문 목차 및 집필 기준

최초 작성: 2026-10-16
목차 개정: 2026-11-01

제목: **가상 CAN 환경에서 저속 주행 정지 요청 기능의 메시지 이상 대응 검증**

사용자의 요청에 따라 기존 6장 구성을 5장, 10개 절로 줄였다. 중복된 설계와 시험 방법 설명을 합치고, 이미 작성한 1장과 3장의 내용을 최대한 활용한다. 이번 변경은 집필 구성의 조정이며 제출한 작성계획서나 연구 설계 기준선 v1.0을 변경하지 않는다.

## 본문 목차

### 제1장 서론

- 제1절 연구 배경 및 필요성
- 제2절 연구 목적 및 범위

배경과 문헌 근거, 연구 질문과 검증 범위를 설명한다. 별도 '논문의 구성' 절은 두지 않는다.

### 제2장 관련 기술

- 제1절 CAN 통신과 가상 검증 환경
- 제2절 수신 타임아웃과 순번 갱신 감시

CAN/SocketCAN/vCAN, CARLA의 역할과 두 감시 방식의 원리만 설명한다. 참고 구현은 관련 설명 안에서 인용하고, 직접 구현한 부분과 구분한다. 설치 절차나 코드 파일별 소개를 별도 절로 늘리지 않는다.

### 제3장 검증 시스템 및 시험 방법

- 제1절 요구사항 및 시스템 구성
- 제2절 메시지 규격 및 정지 요청 로직
- 제3절 시험 환경 및 시나리오
- 제4절 평가 지표 및 판정 방법

제1절은 R-01~R-09 요약표와 송신기, SUT, adapter, 독립 관측기의 구조를 다룬다. 제2절은 자체 메시지 규격과 A/B 감시 로직, 기동/arm 및 정지 잠금을 설명한다. 제3절은 실제 실행 환경, 고정 차량 조건, 4개 시나리오와 80회 실행 순서를 정리한다. 제4절은 독립 로그, 요청 관찰/제어 호출/차량 정지의 기준, 호스트 시간과 시뮬레이션 시간의 구분, 실패와 실행 오류의 집계 방법을 정의한다.

요구사항과 수치는 RESEARCH_BASELINE.md 및 VALIDATION_PLAN.md를 따른다. 연구용 설계값을 표준이나 양산 기준으로 표현하지 않는다. 사전 정의 거리 입력과 CARLA에서 관찰하는 차량 반응의 역할을 구분한다.

### 제4장 시험 결과 및 분석

- 제1절 시나리오별 시험 결과
- 제2절 방식별 비교 및 한계

제1절은 기본 연결 확인을 짧게 정리한 뒤 정상 조건과 메시지 이상 조건의 실제 결과를 표와 대표 그래프로 제시한다. G0~G4를 각각 별도 절로 만들지 않는다. 제2절은 A/B의 요구사항 충족 차이와 응답시간을 비교하고, 실패 원인과 검증 범위를 해석한다. 제3장의 시나리오와 판정 기준을 다시 설명하지 않고 번호로 참조한다.

현재 확보한 실측은 G3까지다. G4, 예비시험, 본시험 결과와 비교 수치는 실제 수행 후에만 채운다. 연결 시험의 제동 성공을 거리 이상 검출이나 전체 요구사항 검증 결과로 확대하지 않는다.

### 제5장 결론

절을 나누지 않는다. 수행한 연구와 실제 결과가 연구 질문에 주는 답, 후속 과제를 간결하게 정리한다. 제4장의 표와 한계 설명을 반복하지 않는다.

## 분량 배분

표와 그림을 포함한 본문 20쪽을 집필 기준으로 잡는다. 아래는 시험 완료 후의 목표 배분이며 현재 작성 분량이나 결과 확보 상태를 뜻하지 않는다. 학과의 공식 20매 산정 범위가 확인되면 그 기준을 우선한다.

| 장 | 목표 분량 |
| --- | --- |
| 제1장 서론 | 2쪽 |
| 제2장 관련 기술 | 2쪽 |
| 제3장 검증 시스템 및 시험 방법 | 8쪽 |
| 제4장 시험 결과 및 분석 | 7쪽 |
| 제5장 결론 | 1쪽 |
| 합계 | 20쪽 |

참고문헌, 표목차, 그림목차, 초록은 본문과 별도로 배치한다. 이 편집 계획이 이 항목들을 학과의 최소 분량 산정에서 제외한다는 공식 해석은 아니다. 부록은 필수로 늘리지 않고 재현용 전체 자료는 저장소를 참조한다.

## 중복을 줄이는 집필 원칙

- 제2장은 기술 원리, 제3장은 본 연구의 설계와 시험 방법, 제4장은 실제 관측 결과와 해석을 맡는다.
- 요구사항, 메시지 규격, 시나리오, 판정 기준은 각각 한 번만 정의한다.
- 원시 로그 전체, 설치 명령, 모든 코드와 단위 검사 목록을 본문에 옮기지 않는다. 필요한 표와 대표 그래프를 선별하고 재현 경로를 제시한다.
- 표와 그림은 장 기준으로 번호를 붙인다. 제3장의 첫 표는 표 3-1이며 절 번호로 결정하지 않는다.
- 결론 초안과 교수 피드백 자료에도 수행 상태를 명시한다. 예상 결과를 관찰 결과로 쓰지 않는다.

기존 제3장 설계와 제4장 시험 방법을 새 제3장으로 합치고, 기존 제5장 결과는 새 제4장, 기존 제6장 결론은 새 제5장으로 옮긴다. 이미 작성한 본문은 이 배치에 맞춰 이동하고 겹치는 설명만 정리한다.
