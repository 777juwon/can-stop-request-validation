# 졸업논문 챕터별 구성 최종안 v1.0

작성일: 2026-10-16

제목: **가상 CAN 환경에서 저속 주행 정지 요청 기능의 메시지 이상 대응 검증**

본문을 작성할 구성 기준이다. 이미 제출한 계획서를 변경하거나 실험하지 않은 결론을 미리 확정하는 문서가 아니다. 학과 양식의 편집 규정은 최종 편집 시 따른다.

## 제1장 서론

- 1.1 연구 배경: 프레임 도착과 새로운 정보의 갱신을 구분해야 하는 이유. 응용 메시지 이상과 실제 센서 고장 진단의 차이.
- 1.2 목적과 연구 질문: 메시지 중단과 동일 프레임 반복에서 두 감시 방식의 요구사항 충족 범위를 비교. 검증 체계가 중심임을 설명.
- 1.3 범위와 구성: 소프트웨어 ECU 역할, vCAN, CARLA와 4개 시험. 실차 안전성 및 물리 CAN 오류는 제외.

## 제2장 관련 기술 및 참고 구현

- 2.1 CAN, SocketCAN과 vCAN: ID, 필터와 가상 인터페이스. 목적지 주소 및 물리 ACK와 구분.
- 2.2 수신 타임아웃과 순번 갱신: 반복, 정상 전진과 회전. 새 순번만으로 실제 측정 최신성을 보장하지 못하는 한계.
- 2.3 CARLA와 시간 기준: 차량 제어, 동기 실행, 시뮬레이션 시간과 호스트 시간의 차이.
- 2.4 참고 구현과 직접 구현: SOURCE_AUDIT의 commit과 라이선스 인용. 차용, 수정, 직접 구현을 구분. 공개 mock 테스트를 본 연구 실행 결과로 쓰지 않음.

## 제3장 요구사항 및 검증 시스템 설계

- 3.1 연구용 요구사항과 수치의 근거: R-01~R-09 및 50 ms, 200 ms, 2 m 등의 이유. 표준이나 양산 기준이 아님을 명시.
- 3.2 시스템 구조와 메시지: 송신, 판단, adapter, 독립 observer의 구조도와 자체 DBC 표.
- 3.3 두 방식과 상태 전이: 순번 인정 규칙, 기동 억제, arm, 정지 잠금과 수동 초기화.
- 3.4 이상 주입과 독립 판정: 중단과 동일 payload 반복의 차이, 송신 경계, CAN 관찰과 차량 상태.

## 제4장 시험 구성 및 수행 방법

- 4.1 실행 환경과 최소 연결: 실제 확인한 OS, kernel, GPU/driver, Python, 라이브러리, CARLA, map, 차량 및 spawn. G0~G4 증거.
- 4.2 시나리오와 실행 순서: T-01~T-04 입력, fault 구간과 복원, 잠금, 80개 실행과 교대 순서. 거리는 수치 시퀀스임을 명시.
- 4.3 평가 지표와 판정: 요청 관찰, 제어 호출과 정지의 기한을 분리. 실패, 실행 오류, 증거 누락과 추가 실행 집계.

## 제5장 시험 결과 및 분석

- 5.1 정상 조건: 불필요 요청과 근거리 요청, 동일 거리의 정상 갱신과 counter 회전.
- 5.2 메시지 이상: 방식별 요구사항 충족 표와 요청 시간. 예상과 다른 결과도 원시 로그에 따라 분석.
- 5.3 차량 반응: adapter 처리와 실제 CARLA frame 및 속도 그래프. 전달 성공을 정지 성공으로 대체하지 않음.
- 5.4 실패와 한계: 원래 80개 시도의 모든 실패 및 오류, 고정 입력 반복, 고정 차종과 설정, 물리 CAN 미재현의 한계.

## 제6장 결론

- 6.1 수행 내용 요약: 실제 구현하고 수행한 범위만 정리.
- 6.2 연구 질문의 답: 실제 결과표를 근거로 방식별 충족 및 미충족 요구사항을 설명. 아직 결과가 없으므로 이 절의 효과 및 수치는 현재 작성하지 않음.
- 6.3 의의와 후속 과제: 요구사항에서 독립 증거로 이어지는 검증 절차의 의의. 실차 안전성, 임의의 센서 고장 검출과 자동 재출발은 입증하지 않았음을 명시.

## 참고문헌과 부록

- 공식 문서, 공개 구현과 참고 논문.
- 요구사항-시나리오-증거 추적표, DBC, 체크시트와 실행 명령.
- 결과표와 원시 로그 위치 및 재현 절차.

## 교수 피드백용 자료

최종 제출 약 1.5개월 전에는 챕터별 개요와 그때까지 확보한 예비 결과 및 결론 초안을 보낸다. 결과가 없으면 본시험 전으로 미확정이라고 명시한다. 예상 결과를 관찰 결과로 쓰거나 수치를 만들지 않는다. 논문 구성의 최종 확정이 실험 결론까지 이미 확정됐다는 뜻은 아니다.
