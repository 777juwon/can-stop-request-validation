이 문서는 중간점검 커밋 `9109b3c` 시점의 기록이다. 이후 adapter 핵심 구현은 [G3_ADAPTER_STEP](G3_ADAPTER_STEP.md), 최신 상태는 [STATUS](STATUS.md)를 따른다.

현재 위치: **환경 설치와 개별 연결을 실제로 확인한 단계**다. 다음은 CAN 요청을 CARLA 차량 제동에 연결하는 adapter 구현이다. 논문의 핵심인 A/B 제어기, 이상 입력 비교와 본시험은 아직 남아 있다.

## 1. Git에 어디까지 저장했는가

이 작업 시작 시 로컬 HEAD와 직접 조회한 GitHub main은 모두 `94411a4`였다. 2026-10-16의 설계 문서 커밋이다. 이후 작성한 코드와 실행 증거는 파일로 저장돼 있었고 새 Git 커밋은 없었다.

이번 중간점검에서는 설치 도구, 검사 코드, 실행 증거와 이 보고서를 로컬 체크포인트 커밋으로 묶는다. 원격 push는 별도 단계다. 해당 스냅샷에서 커밋 해시와 원격 전달 상태는 다음 명령으로 확인한다.

```bash
git log -1 --oneline
git status --short --branch
git log --oneline origin/main..HEAD
```

push는 이미 만들어진 커밋을 GitHub로 보낸다. 커밋하지 않은 파일 변경은 push만으로 전달되지 않는다. 중간점검용 커밋을 push하면 다른 환경에서도 같은 코드와 증거를 검토할 수 있다. CARLA 패키지와 .venv는 Git 제외 대상이다.

요구사항과 시험 계획 문서는 이미 준비돼 있다. 앞으로 구현 및 실행으로 그 문서를 채우고, 결과와 한계를 분석해야 한다. 본문 초안 상태는 이 저장소 기준이며 외부 개인 문서를 검색한 결과가 아니다.

본시험의 명목 입력 구간 합계는 80회 x 20초 = **26분 40초**다. 실제 작업 시간에는 구현, 준비와 안정화, 환경 오류 대응, 로그 검토, 분석과 집필이 더해진다. 45~90분이라는 앞선 예상은 G3 한 단계에 대한 추정이며 논문 전체 잔여 시간은 아니다.

## 4. 다음 한 번의 작업 범위

다음은 adapter의 정상 수신과 제동 호출을 구현하고 단위 검사하는 작업으로 제한한다. 이후 실제 CARLA 연결을 별도 단계로 확인한다. 잘못된 StopRequest와 미정의 값에 대한 정책은 구현 전에 기준선에서 확인하고, 추가 결정이 필요하면 이유와 제안을 먼저 남긴다.

| 확인 순서 | 필요한 증거 |
| --- | --- |
| CAN 요청을 받았는가 | 수신 ID/payload/token과 호스트 시각 |
| 제동 호출을 완료했는가 | 호출 전후 시각, 응답과 actor ID |
| 차량에 실제 적용됐는가 | 다음 tick 이후 적용 제어와 frame |
| 실제로 감속하고 정지했는가 | CARLA 평면 속도와 연속 정지 구간 |

## 5. 현재의 미해결 항목

- CARLA의 Ctrl+C 종료에서 Signal 11/exit 139를 두 번 관측했다. actor/settings 정리 성공과 서버의 정상 종료는 별도로 기록한다.
- adapter의 잘못된 요청 처리와 요청 순번 정책은 아직 확정하지 않았다.
- 교수 피드백과 본문 검토 결과는 현재 저장소에 기록된 근거가 필요하다. 설계 문서 확정을 교수 승인으로 표현하지 않는다.
